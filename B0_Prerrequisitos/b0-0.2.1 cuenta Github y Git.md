## 🎯 Qué se pedía

[](https://github.com/jholopzam/apuntes-sor-t1/blob/main/B0_Prerrequisitos/b0-0.2.1%20cuenta%20Github%20y%20Git.md#-qu%C3%A9-se-ped%C3%ADa)

Cree y configure una cuenta en GitHub junto con la instalación de Git local. El objetivo era vincular ambas plataformas para poder gestionar el control de versiones y subir código a la nube.

## ⌨️ Comandos y pasos importantes

[](https://github.com/jholopzam/apuntes-sor-t1/blob/main/B0_Prerrequisitos/b0-0.2.1%20cuenta%20Github%20y%20Git.md#%EF%B8%8F-comandos-y-pasos-importantes)

- - `git config --global user.name "TuNombre"`— Configura el nombre de usuario global que identificará tus commits.
- `git config --global user.email "tu@email.com"`— Asocia tu dirección de correo electrónico a los cambios que realizas en Git.
    
- `git --version`— Verifica que Git esté correctamente instalado en el sistema.
    
- `ssh-keygen -t ed25519 -C "tu@email.com"`— Genera un par de claves SSH para autenticarte de forma segura con GitHub.
