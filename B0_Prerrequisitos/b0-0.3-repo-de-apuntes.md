## ⌨️ Comandos y pasos importantes

- **pwd**— muestra la ruta de la carpeta actual en la terminal para no hacer git init en el sitio equivocado.
    
- **git init**— convierte la carpeta actual en un repositorio de Git.
    
- **git branch -M main**— renombra la rama principal a main.
    
- **git status**— enseña los archivos modificados o listos para guardar.
    
- **git remote add origin** — conecta el repositorio local con el repositorio remoto en GitHub.
    
- **git add** — añade un archivo específico al área de preparación.
    
- **git commit -m "mensaje"**— guarda los cambios preparados en el historial con un mensaje descriptivo.
    
- **git push -u origin main**— sube los cambios locales al repositorio en GitHub.
    
- **q**— sale del paginador (less) cuando la pantalla se queda atascada al usar git log o git diff.
